-   **[Embedding items in an iframe](ref_embed_iframe.md)**

-   **[Embedding API](ref_embedding_api.md)**  
The Embedding API can be used to embed a {{shortLeapProductName}} form directly in another webpage without using an <iframe\>. The {{shortLeapProductName}} form will be inserted into the DOM of the hosting page and can be interacted with using the {{shortLeapProductName}} JavaScript API or any custom JavaScript. Additionally, the style of items in the {{shortLeapProductName}} form can be customized by the CSS of the hosting page.
-   **[Creating customized Cascading Style Sheets](ref_customized_css.md)**  
You can apply your own custom Cascading Style Sheet \(CSS\) to the rendering of your {{fullLeapProductName}} application. To create a custom theme, you must be familiar with the basic concepts of CSS.
